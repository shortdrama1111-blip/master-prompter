## 0. GLOBAL SETTINGS (same for every scene)

| Setting | Value |
|---|---|
| Resolution | **720 × 1280** (9:16) |
| Frame rate | **24 fps** |
| Frame start | 1 (each scene in its own file or its own frame range) |
| Shading | Solid → Color: **Object**, every object gets its colour from the key below |
| Render | View → **Viewport Render Animation** (MP4, H.264) |
| Multiple cameras | one camera per shot, **Marker → Bind Camera to Markers** at each cut frame |
| Scale | 1 Blender unit = 1 m. A person = capsule 1.75 m (kid 1.35 m, teen 1.65 m). A car = box ~4.5 × 1.9 × 1.2 m |
| Speeds | 60 km/h = 16.7 m/s = **0.69 m per frame** · 90 km/h = 25 m/s = **1.04 m/frame** · 120 km/h = 33.3 m/s = **1.39 m/frame** |

| 84° wide | 18 mm |
| 63° | 28 mm |
| 47° | 40 mm |
